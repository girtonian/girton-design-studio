04 — Motion Reference

The language
under everything.

// ENTER ANIMATION (Jakub)
opacity: 0 → 1
translateY: 10px → 0
filter: blur(5px) → blur(0)
duration: 600ms, ease-out
stagger siblings: +80ms each
// EXIT ANIMATION (Jakub)
opacity: 1 → 0
translateY: 0 → -8px ← subtler than enter
filter: blur(0) → blur(4px)
duration: 300ms
Exits: never compete for attention
// CARD HOVER
transform: translateY(-3px)
box-shadow: deepens to sage tint
border-color: → sage-light
gradient overlay: fades in
arrow: translate(-4px,4px) → (0,0)
// FRAGMENT DRIFT (Jhey @property)
@keyframes: opacity 0→.55→0
translate: fx,fy → fx2,fy2 per element
rotate: fr → fr2
duration: 8–14s, linear float easing
Each fragment: unique CSS vars inline
// SCROLL LINE
position: fixed, left edge
scaleY: tied to window.scrollY %
transform-origin: top
color: var(--sage)
width: 2px — edge detail only
// ACCESSIBILITY RULE
@media (prefers-reduced-motion)
All durations: 0.01ms
.fragment { display: none }
— Never animate what isn't wanted.
— Non-negotiable.
