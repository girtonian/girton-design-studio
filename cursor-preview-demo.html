Pattern: Cursor-as-Preview

  • Spring-physics cursor following — no jitter, no lag spikes
  • Per-project gradient + emoji placeholder (swap for real screenshots)
  • Velocity-based tilt: fast cursor movement tilts the card naturally
  • Left/right awareness: card flips sides when near viewport edge
  • Entrance/exit scale animation with cubic-bezier spring easing
  • Context-aware cyan dot shrinks when hovering links
  • Zero dependencies — pure Vanilla JS, drop into any React component

React Integration (copy into your portfolio)

// hooks/useCursorPreview.ts import { useEffect, useRef } from 'react'; export function useCursorPreview() { const pos = useRef({ x: 0, y: 0 }); const target = useRef({ x: 0, y: 0 }); const raf = useRef(null); useEffect(() => { // spring lerp loop — 0.12 = snappy but smooth const loop = () => { pos.current.x += (target.current.x - pos.current.x) * 0.12; pos.current.y += (target.current.y - pos.current.y) * 0.12; // apply to DOM node… raf.current = requestAnimationFrame(loop); }; raf.current = requestAnimationFrame(loop); return () => cancelAnimationFrame(raf.current); }, []); }
