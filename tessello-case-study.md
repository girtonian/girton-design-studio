# Tessello — Case Study
### Parametric Figma Pattern Studio · Contra × Figma Makeathon 2026

---

## The Frame

> "Existing pattern tools give you pre-baked outputs you can shuffle around. Tessello gives you a parametric engine — and lets you paste any SVG and turn it into a repeatable tile in seconds."

---

## The Problem

Every designer has spent hours trying to get the right background pattern.

The existing options all have the same problem: they're static. Services like Heropatterns give you a library of pre-baked outputs. Figma's native repeat grid gets you partway there. But none of them let you *design the pattern* — adjust parameters live, stack layers, or bring in your own shapes.

Pattern tools treat patterns as finished things. Tessello treats them as variables.

When Contra and Figma issued a Makeathon challenge to build something genuinely useful for designers, this was the right problem to solve.

---

## What Tessello Is

**A parametric pattern engine, built entirely in Figma Make. No plugins. No backend. No local setup. Runs completely in the browser.**

You start with a default pattern and adjust from there. Two categories of pattern types:

**8 Core Patterns**
Grid · Isometric · Triangle · Voronoi · Wave · Pinwheel · Penrose

These range from the structurally predictable (grid, isometric) to the mathematically unusual (Penrose is aperiodic — it tiles infinitely without ever repeating; Voronoi emerges from point proximity rather than a grid).

**8+ Decorative Elements**
Scallop · Moroccan · OG · Cross · Arrow · Dot Matrix · Lozenge · Basket

Each can be customized and adjusted to fit the specific pattern need.

## The Features That Matter

### 1. Pattern Stacking
Stack pattern types on top of one another. This is where it gets genuinely interesting — two patterns overlapping create emergent texture. The demo shows a result that reads like industrial steel plate: something you wouldn't have arrived at by choosing a single pattern type, but that emerges naturally from layering two.

### 2. SVG Paste-to-Pattern
This is the feature that separates Tessello from every other pattern tool.

Copy any SVG — an icon, a logo mark, a shape from a previous project. Come back to Tessello. Select the layer. Ctrl+V. The SVG drops into Tessello's 100×100 tile canvas and instantly becomes a repeatable pattern.

Any icon becomes a repeating pattern. Any mark becomes a surface system. This turns Tessello from a pattern selector into a custom pattern studio.

### 3. Fully Parametric Controls
Every pattern type exposes live controls. Adjust and see it update in real time. The workflow is: pick a type → tune the parameters → decide it's done → export.

### 4. Three Export Paths
- **SVG** — editable, scalable, works everywhere
- **PNG** — flat raster for immediate use
- **Figma-native** — drops directly onto the canvas as a Figma object

## Process

**The constraint was the canvas.**
Figma Make is a relatively new environment. Building a parametric engine with real-time parameter controls, pattern stacking, and SVG paste — with no backend and no plugins — inside Figma Make required working within its specific constraints and capabilities. The entire tool runs in the browser.

**The mathematical pattern choices were deliberate.**
Including Penrose was a statement. It's aperiodic tiling — a mathematical object that most designers have never had access to without writing code. Putting it in a point-and-click interface, alongside grid and isometric, means the range goes all the way from "I need a simple background" to "I want something that's genuinely unusual and has mathematical depth."

Voronoi has similar weight. The shape comes from the data — it's generated by proximity between points, not defined by a grid. As a result, it produces organic-feeling geometry that holds up to scrutiny because it has underlying logic.

**The SVG feature emerged from real designer behavior.**
Designers have existing assets. The insight that you can treat *any* icon or shape as a repeating tile means Tessello works for brand systems — not just for decoration. Your logo mark, your icon set, your custom glyphs — all of them become raw material.

## What I'd Build Next

Pattern stacking is the beginning of a larger idea: pattern systems that respond to inputs. Color modes that adapt to the geometry. Parameter sets that can be saved, shared, and remixed as design tokens. Animation of parameters as a motion primitive. The mathematical foundations are already in place — the surface is barely scratched.

## What This Demonstrates

**Creative Technology depth** — Penrose and Voronoi aren't Figma tutorials. They're mathematical systems brought into a live GUI without code.

**Product instinct** — Every feature decision serves a real workflow: stack for complexity, SVG paste for custom marks, three export formats for different downstream uses.

**Toolmaking mindset** — Designers who build tools for other designers see design problems differently. Tessello exists because the existing tools were wrong, not because a brief asked for it.

**Execution under constraint** — No backend. No plugins. A tight Makeathon window. All of it shipped.
